# WO 작업 규칙 (이 폴더 전용)

이 폴더(`docs/work-orders/`)의 파일을 생성/수정/조회할 때는 **반드시** 아래 규칙을 따릅니다.
이 문서는 `PROGRESS.md` 갱신의 단일 진실 소스(SSOT)입니다.

## PROGRESS.md 갱신 규칙

`PROGRESS.md`는 WO 파이프라인의 현재 진행 상태를 한눈에 보기 위한 문서입니다.
`/check`, `/fix-check`, `/start`, `/review`, `/fix-review` 슬래시 커맨드는 작업 종료 시 **반드시** 이 문서를 갱신해야 합니다.

### 1. 표 구조 (절대 변경 금지)

| WO | check | fix-check | start | review | fix-review |
|----|:---:|:---:|:---:|:---:|:---:|
| WO-XXX | O | - | O | O | - |

- **컬럼은 정확히 6개** (WO + 5단계). 늘리거나 줄이지 않습니다.
- 단계 컬럼 순서는 `check → fix-check → start → review → fix-review` 고정.
- 정렬: 가장 최근에 갱신된 WO가 **맨 위**에 오도록 정렬합니다.

### 2. 셀에 들어갈 수 있는 값 (이 3개 외 절대 금지)

| 기호 | 의미 |
|------|------|
| `O` | 통과 / 완료 |
| `X` | 실패 / 수정 필요 (현재 미해결 상태) |
| `-` | 미진행 또는 불필요 |

- **반드시 대문자** `O`/`X`만 허용. 미진행은 하이픈 `-` 하나.
- 사용 금지 예시: `o`, `x`, `✓`, `✅`, `❌`, `OK`, `완료`, `done`, 빈 칸 등.

### 3. 단계별 갱신 규칙 (어느 칸을 어떻게 바꾸는가)

각 슬래시 커맨드는 **자기 단계의 칸만** 갱신합니다.
**다른 WO의 행은 절대 건드리지 않습니다.**

#### `/check WO-XXX`
- 해당 WO 행이 없으면 새 행을 만들고 5칸 모두 `-`로 초기화한 뒤 갱신.
- 검수 결과 PASS → `check` 칸을 `O`로.
- 검수 결과 FAIL → `check` 칸을 `X`로.
- 다른 칸은 손대지 않음.

#### `/fix-check WO-XXX`
- 모든 문제 해결 → `check` 칸을 `O`로 + `fix-check` 칸을 `O`로.
- 미해결 / 사용자 결정 대기 → `check` 칸은 `X` 유지 + `fix-check` 칸을 `X`로.
- **핵심**: fix-check가 성공하면 **check 칸도 함께 `O`로 바뀐다.**
  (`X`는 "현재 미해결 상태"일 때만 표에 존재합니다.)

#### `/start WO-XXX`
- 선행 단계(`check`)가 `O`가 아니면 작업을 시작하지 않고 사용자에게 보고합니다.
- 작업 완료 → `start` 칸을 `O`로.

#### `/review WO-XXX`
- 검토 결과 PASS → `review` 칸을 `O`로.
- 검토 결과 FAIL → `review` 칸을 `X`로.

#### `/fix-review WO-XXX`
- 모든 문제 해결 → `review` 칸을 `O`로 + `fix-review` 칸을 `O`로.
- 미해결 / 사용자 결정 대기 → `review` 칸은 `X` 유지 + `fix-review` 칸을 `X`로.
- **핵심**: fix-review가 성공하면 **review 칸도 함께 `O`로 바뀐다.**

### 4. "현재 작업" 라인

`PROGRESS.md` 상단의 `**현재 작업**:` 라인은 **지금 진행 중인 단일 WO와 단계**를 가리킵니다.

- 슬래시 커맨드 시작 시: `**현재 작업**: WO-XXX (단계: <단계명>)`로 갱신.
- 커맨드 정상 종료 시: `**현재 작업**: (없음)`으로 비웁니다.
  - 예외: 즉시 다음 단계가 필요한 경우(예: check가 `X`로 끝나 fix-check 필요)에는 다음 단계를 명시 가능.

### 5. "현재 단계 메모" 섹션

표 아래의 자유 형식 메모. 진행 중 발견한 이슈/막힌 지점/다음 액션을 짧게 기록합니다.

- 형식: `- WO-XXX / <단계>: <내용>`
- 해당 WO가 완료(모든 칸이 `O` 또는 `-`)되면 메모도 정리합니다.

### 6. 안전장치 (갱신 전 반드시 확인할 체크리스트)

1. 갱신하려는 WO 번호가 현재 커맨드 인자와 정확히 일치하는가?
2. 표의 컬럼이 정확히 6개인가? (행을 추가/수정한 경우)
3. 셀 값이 `O` / `X` / `-` 셋 중 하나인가? (다른 문자 절대 금지)
4. 다른 WO 행은 건드리지 않았는가?
5. `**현재 작업**` 라인이 표 상태와 모순되지 않는가?

**갱신 도중 표가 손상되었거나 의미가 모호하면 즉시 사용자에게 보고하고 작업을 중단합니다. PROGRESS.md를 임의로 "복구"하거나 "정리"하지 마십시오.**

## 완료된 WO의 모양 (참고 예시)

```
| WO-011 | O | - | O | O | - |   ← 한 번에 통과
| WO-012 | O | O | O | O | - |   ← check에서 한 번 걸렸음
| WO-013 | O | - | O | O | O |   ← review에서 한 번 걸렸음
| WO-014 | O | O | O | O | O |   ← 둘 다 걸렸음
```

`X`는 **현재 미해결 상태일 때만** 표에 존재합니다. 해결되면 `O`로 바뀝니다.
